# MediBook BD

## Setup
1. Import `database.sql` into MySQL (creates `medibook_bd` DB with sample doctors).
2. `npm install`
3. `npm start` — runs on http://localhost:3000

## Pages
- `/` — Home
- `/doctors.html` — Doctor list with search/filter
- `/appointment.html` — Book appointment, check status, cancel/reschedule
- `/doctor-dashboard.html` — View all appointments, update status (Confirmed/Completed/Cancelled)
