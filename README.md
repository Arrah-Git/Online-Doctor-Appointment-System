# 🩺 MediBook BD - Online Doctor Appointment System

**MediBook BD** is a comprehensive full-stack web application designed to streamline the process of finding specialized doctors and booking medical appointments seamlessly across Bangladesh.

---

## 🌟 Key Features

* **🔍 Smart Doctor Discovery:** Browse through a rich directory of specialist doctors with search and filter options.
* **📅 Hassle-Free Booking:** Book appointments easily with real-time slot selection and instant confirmation tracking.
* **📋 Management Dashboard:** Dedicated doctor and admin dashboard to oversee, update, and manage appointments (Confirmed, Completed, Cancelled).
* **📱 Responsive Interface:** Clean, modern, and user-friendly UI built for all devices.

---

## 📂 Pages & Navigation

* ` / ` — **Home Page:** Overview, featured specialists, statistics, and patient testimonials.
* ` /doctors.html ` — **Doctors Directory:** Comprehensive list with advanced search and specialty filters.
* ` /appointment.html ` — **Appointment Portal:** Streamlined interface for booking, status tracking, and scheduling.
* ` /doctor-dashboard.html ` — **Dashboard:** Centralized hub to view all appointments and update their status.

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Backend:** Node.js, Express.js
* **Database:** MySQL
